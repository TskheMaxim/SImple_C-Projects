# SImple_C++_Projects

A collection of beginner-friendly C++ programs built for learning and practice.

## 1. Interactive Console Calculator

An interactive command-line calculator that performs fundamental arithmetic operations in a continuous user loop.

### Features
* **Operations Supported:**
  * Addition (`+`)
  * Subtraction (`-`)
  * Multiplication (`*`)
  * Division (`/`)
* **Error Prevention:** Built-in validation to prevent division by zero errors.
* **Interactive Menu Loop:** Stays open allowing multiple calculations until option `5` (Exit) is selected.

## How to Compile and Run

### Prerequisites
* GCC compiler (`g++`) installed (e.g., MinGW/MSYS2 on Windows).
